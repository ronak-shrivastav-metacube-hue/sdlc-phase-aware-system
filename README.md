# SDLC AI Agent - Feature Request Management System

An automated, intelligent system designed to capture, classify, and generate artifacts for software feature requests using LangChain and OpenAI.

## Features
- **Secure CLI Interface:** Interactive menu with input sanitization and rate-limiting.
- **AI Phase Detection:** Powered by LangChain and OpenAI (`gpt-3.5-turbo`) with few-shot prompting.
- **Automated Artifact Generation:** Instantly creates markdown documents for Requirements, Design, Implementation, Testing, and Deployment.
- **Analytics & Visualizations:** Keyword frequency analysis and automated chart exports.
- **Operational Monitoring:** Real-time dashboards tracking success rates, response times, and error logs.
